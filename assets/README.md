# LUX Pilates assets

Place the opening reel in this folder with this exact filename:

`lux-hero.mp4`

Recommended export:
- Format: MP4
- Video codec: H.264
- Aspect ratio: 9:16
- Original reel size: 1080 × 1920
- Audio is not required for the hero because browsers autoplay it muted.

The home page expects the file at:

`assets/lux-hero.mp4`
